📦 프로젝트 준비

촬영에 나갈 장비 구성을 만들어, 확정하면 소싱 라인(재고·준비·반납의 원천)으로 만듭니다. ⓪붙여넣기 → ①고르기 → ②확인 → ③프로젝트 지정 순서.

🧭 전체 수순
  1. (선택) ⓪ 포토 리스트 붙여넣기 → ↓ 줄 만들기·자동 매칭 → 매칭 확인·교체 → ✅ 담기
  2. ① 카테고리에서 우리 장비를 추가로 고르기
  3. ② 준비 리스트에서 수량·업체배분·날짜·노트 확인
  4. ③ 프로젝트·출고/반납일 정하고 ✅ 이 구성으로 라인 만들기

⓪ 포토 리스트 붙여넣기 (초록 패널)

포토가 준 리스트를 그대로 붙여넣고 ↓ 줄 만들기·자동 매칭을 누르면, 각 줄을 우리 장비와 자동으로 맞춰줍니다. (지우기로 비움)

인식하는 형태: 3 X 품명, 2M 품명, 품명 x 2 등에서 수량을 떼어냅니다. 섹션 제목(LIGHTS·GRIP…)·안내문은 무시.

🔎 매칭 확인 표 — 제목의 숫자 뜻

제목: “매칭 확인 (총 N · 매칭 M · 확인필요 K)”

  • 총 N = 붙여넣어 만든 전체 줄 수
  • 매칭 M = 실제 우리 장비가 연결된 줄 수
  • 확인필요 K = 못 찾았거나 / 매칭됐어도 신뢰도가 낮은 줄 수 (그래서 매칭+확인필요 합이 총보다 클 수 있어요)

  • 토글 ✓ 품목(모델)별 묶어보기
  • KPI: 전체 품목 / 재고 0(대여불가) / 검색 결과

표 · 팝업

  • 묶어보기 열: EQ_NO·카테고리·브랜드·품목명(N대)·총보유·실재고·사용현황(나간 프로젝트, 겹침 N)·위치. 줄 클릭 → 개체 상세 팝업
  • 개체 상세 팝업: 개체별 시리얼·실재고·현재 위치(출고중/보관)·특이사항. 재고현황에서는 보기 전용(수정은 장비 마스터에서)
  • 사용이력(＋N건): 라인ID·수량·출고·반납·상태
⚙️ 겹침(부족)이란 아직 반납 안 된 예약들이 같은 날 동시에 보유 수량보다 많이 잡히면 “겹침”으로 경고합니다(장비 부족 위험).

📋 복붙 모드 (여러 표 공통)

표의 원하는 칸만 엑셀처럼 골라 복사·붙여넣기. 준비 리스트(②)·준비·랩업·반납 표 위에 있습니다.

  1. 📋 복붙 모드 켜기 — 켜면 칸 입력이 잠기고 선택 모드
  2. 칸을 클릭 / 드래그 / Shift+클릭으로 원하는 만큼 선택
  3. 복사 ⌘C
  4. 넣을 칸 선택 → 앱에 붙여넣기 ⌘V (또는 카톡·시트에 ⌘V)
  5. 잘못했으면 ↩︎ 되돌리기
  • 한 칸 복사 → 넓은 범위 붙여넣기 = 전부 같은 값 (예: 준비상태 100개 한 방)
  • 품명·수량만 골라 복사 → 카톡에 붙여넣으면 목록으로 나감
  • 앱 안 붙여넣기는 입력 가능한 칸에만 (읽기전용 칸·15칸↑은 확인)

🔧 파손·분실

상단 토글 🔧 파손·이력 / 🚩 분실.

🔧 파손·수리 이력

파손된 장비 1개 = 1줄로 수리를 관리합니다. 반납에서 파손 입력된 건이 접수 대기로 떠요.

  • 🔴 접수 대기 N건: ＋ 수리 접수로 이력에 등록
  • 상태 칩 전체 접수 수리중 수리완료 폐기
  • 이력 열: 수리ID·프로젝트·품목·EQ_NO·진행상태(드롭다운)·증상/수리내용·수리업체·수리비용·결제방법·비용귀속·완료일·비고·✕
⚙️ 자동 수리완료로 바꾸면 → 그 장비가 실재고로 복귀(완료일 자동). 폐기로 바꾸면 → 보유수량 −1 영구 제거(폐기 취소하면 원복).

🚩 분실

반납에서 ‘분실’로 적힌 장비 모음. 열: EQ_NO·품목·프로젝트·분실 수량·반납자·날짜·✓ 찾음 −1(여러 개면 전체 찾음).

⚙️ 자동 찾음 처리 → 분실 수량 −1 → 실재고 복귀.
프리랜서 이 탭 없음.
