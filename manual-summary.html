이 앱은 뭐예요?

각 단계에서 누가·무엇을·언제 확인했는지 적으면, 그게 그대로 회사 기록에 남습니다.

🤔 왜 세 번이나 확인하나요? 장비가 나갔다 오는 사이 어디서 빠지거나 깨졌는지를 놓치지 않기 위해서예요. 창고 나갈 때(준비)·현장 뜰 때(랩업)·돌아왔을 때(반납) 각 시점에 한 번씩 확인하면, 문제가 어느 단계에서 생겼는지까지 알 수 있습니다.
💡 종이 대신인 이유 종이는 잃어버리고, 한 사람만 볼 수 있어요. 이 앱은 2명 이상이 동시에 같은 프로젝트를 봐도 서로 입력이 실시간으로 보입니다.

📗 백업 0번시트
필요할 때 복사→붙여넣기. 견적서는 여기 시트에서 만듦.
🤔 왜 "앱이 원본, 시트는 백업"인가요? 앱과 시트 양쪽에서 다 고치면 서로 안 맞고 꼬입니다. 그래서 정답은 앱 하나로 정하고, 시트는 그 값을 받아 백업 + 견적서 만들기에만 씁니다. 견적서는 상황마다 형태가 달라서 시트에서 유연하게 만드는 게 낫거든요.
💡 "라인ID"가 뭐예요? 같은 장비라도 프로젝트마다 별개의 줄로 관리해야 해요 (A촬영에 나간 카메라 ≠ B촬영에 나간 카메라). 그래서 라인마다 고유번호를 붙여 따로따로 추적합니다.

프로젝트 준비 — 장비 리스트 만들기

📦 프로젝트 준비 탭. 위에서 아래로 ⓪ → ① → ② → ③ 순서예요.

  1. ⓪ 포토 리스트 붙여넣기 (선택) — 포토가 준 장비 리스트를 텍스트로 붙여넣으면 자동으로 우리 장비와 매칭해줍니다. 없으면 건너뛰기.
  2. ① 카테고리 → 보유 장비 고르기 — 카테고리(카메라·조명 등)를 펼쳐 장비별 수량을 정합니다.
  3. ② 준비 리스트 확인 — 고른 장비 + 렌탈이 표로 뜹니다. 여기서 STATUS·수량·조달처를 확인·수정 (아래 설명).
  4. ③ 어느 프로젝트인가 — 프로젝트 이름·출고일·반납일을 정하고 「이 구성으로 라인 만들기」 → 소싱 라인 생성.

② 준비 리스트의 주요 열

열뜻
STATUS이 품목의 확정 상태를 표시 confirm 확정 alt 대체 short/n/a/remove 부족·해당없음·제외
※ 팀 사용 기준에 맞게 — 정확한 뜻은 관리자 확인
조달처어디서 몇 개 나가는지. PA(자사) 몇 개 + 렌탈샵(SLR·HK·조명·왈랄라·데이페이·프로렌탈 등) 몇 개
부족 수량 / 판정보유보다 많이 필요하면 부족분을 렌탈로 자동 표시
일수 · 단가 · 금액일수=반납−출고+1, 금액=단가×수량×일수 (자동 계산)
🤔 왜 부족분이 자동으로 "렌탈"이 되나요? 보유 수량을 넘게 필요하면 사람이 일일이 계산 안 해도 "몇 개 모자라니 렌탈해야 한다"를 앱이 바로 표시해줍니다. 조달처 칸에 렌탈샵별로 몇 개 뺄지 적으면 돼요.

준비 → 랩업 → 반납 (현장 3단계)

📁 프로젝트 탭 → 프로젝트 클릭 → 준비 · 랩업 · 반납 3개 서브탭.

단계언제여기서 하는 일자동으로 되는 것
📦 준비창고 픽업준비상태를 「준비완료」로, 필요하면 노트담당자·시간 자동 기록
🎬 랩업현장 철수챙겨온 장비 랩업상태 확인담당자·시간 자동
↩️ 반납반환반납 체크 · 파손·분실 개수 입력정상 수량·반납상태 자동, 재고 자동 차감
🤔 왜 담당·시간이 자동으로 박히나요? 직원이 따로 이름·시간을 안 적어도, 「준비완료/반납」을 체크한 사람과 그 순간이 자동 기록됩니다. 나중에 "이거 누가 언제 했지?"를 바로 알 수 있어 책임 소재가 분명해져요.
🤔 왜 파손·분실이 재고를 자동으로 깎나요? 재고를 따로 관리하면 반드시 어긋납니다. 반납할 때 파손·분실을 한 번 적으면, 그 수만큼 회사 재고(실재고)가 자동으로 줄어 항상 맞게 유지돼요.
⚠️ 그래서 파손·분실은 꼭 정확히 여기 적은 숫자가 회사 재고를 그대로 깎습니다. 실수로 많이 적으면 재고가 틀어져요.

연관장비 챙기기

품목 옆 🔗 연관장비는 같이 챙겨야 하는 것(배터리·케이블 등)이에요. 누르면 목록이 뜹니다.

  • 준비 화면에서 체크 → 수량과 조달처를 고르는 창이 떠서 그 장비를 프로젝트에 추가
  • 재고 현황에서는 그냥 보기용 목록
🤔 왜 추가할 때 조달처를 고르게 하나요? 누락분으로 추가하는 장비도 PA(자사)에서 챙길지, 렌탈할지가 제각각이라서요. 추가하는 순간 정해두면 조달 정보가 안 빠집니다. (대표 컨펌 후 추가하는 용도)

8

복붙 모드 — 한 번에 여러 개 입력

🆕 새 기능 품목이 많을 때 하나하나 안 하고 엑셀처럼 복사→붙여넣기로 한 번에 채웁니다.
🤔 왜 만들었나요? 나가는 프로젝트가 품목 100개면, 준비상태·수량 등을 하나하나 하려면 손동작이 수백 번이에요. 복붙 모드로 한 번에 처리합니다.

어디서: 준비/랩업/반납 표, 그리고 프로젝트 준비 ② 준비 리스트.

  1. 표 위 「📋 복붙 모드 켜기」 — 켜면 칸 입력이 잠기고 선택 모드
  2. 칸을 클릭 (또는 드래그·Shift+클릭으로 여러 칸·범위)
  3. 복사 (⌘C)
  4. 붙여넣을 칸 선택 → 붙여넣기 (⌘V)
  • 한 칸 복사 → 넓은 범위에 붙여넣기 = 전부 같은 값 (예: 준비상태 100개를 「준비완료」 한 방에)
  • 잘못 붙였으면 ↩︎ 되돌리기 (1회)
  • 같은 종류 칸끼리만 들어갑니다 (안 맞으면 건너뜀 → 실수 방지)

수량+품명 카톡 복사

🆕 새 기능 챙길 장비 목록을 품명+수량만 깔끔하게 복사해서 카톡·시트에 붙여넣기.
  1. 복붙 모드를 켠다
  2. 원하는 품명·수량 칸을 드래그로 선택 (원하는 품목들만 자유롭게)
  3. 복사 (⌘C) → 카톡·시트에 붙여넣기 (⌘V)
🤔 왜 이게 필요한가요? 가끔 "이 장비들 챙겨줘"를 카톡으로 보낼 때, 앱에서 그냥 긁으면 온갖 칸이 다 붙어 지저분해요. 원하는 품명·수량만 골라 깔끔하게 보내려는 겁니다.

소싱시트 백업 · 견적서

📋 소싱시트 탭. 정리된 내용을 백업 시트에 안전하게 넣어둡니다.

  1. 「📋 백업용 전체 복사」 → 그 시점 전체가 복사됨
  2. 「📗 백업 0번시트 열기」 → 시트 데이터 자리(A1)에 붙여넣기 ⌘V
🤔 왜 견적서를 앱에 안 만들고 시트에서 하나요? 견적서는 상황마다 형태가 달라요. 앱은 정확한 값(장비·수량·단가)만 넘겨주고, 그 값으로 견적서는 시트에서 유연하게 만드는 게 낫습니다. 그래서 앱=값 정리, 시트=견적서 제작으로 역할을 나눴어요.
💡 언제 백업? 정리가 끝났거나 중요한 변경 후, 필요할 때. 그 시점 상태가 통째로 백업되고, 나중에 값을 고쳐도 다시 복사하면 최신으로 갱신됩니다.

나머지 탭들

📊 재고 현황

품목별로 묶어 실재고를 봅니다. 줄을 클릭하면 개체별 시리얼·현재 위치가 열려요.

📐 실재고 공식 (자동) 실재고 = 보유 − 분실 − 파손 + 수리완료
그래서 반납에서 파손·분실을 적으면 여기 실재고가 자동으로 바뀝니다. 수리가 끝나면 다시 올라가고요.

🎨 LEE FILTER · SAVAGE (소모자재)

필터·배경지 같은 소모품 잔량을 체크. 50% 이하만 체크 → 구매 필요 신호로 씁니다.

🗂 장비 마스터

회사 전체 장비 DB(약 660개). 시트 원본 그대로 보기, 줄 클릭=편집, 「＋ 새 장비 추가」로 신규 등록. 붙여넣기에서 못 찾은 장비는 「추가여부 검토리스트」로 모여서 등록 여부를 확인합니다.

🧾 매입내역

저장·동시작업 규칙

  • 칸을 다 쓰고 다른 칸으로 넘어가면 저장됩니다 (글자 하나하나가 아니라, 그 칸을 벗어날 때).
  • 실시간 — 2명 이상이 같은 프로젝트를 봐도 서로 수정이 바로 보입니다.
  • 새로고침해도 보던 프로젝트·서브탭 그대로 유지됩니다.
  • 같은 칸을 두 명이 동시에 고치면 나중에 저장한 값이 남습니다.
🤔 왜 실시간이 중요한가요? 창고와 현장에서 2명 이상이 동시에 작업하는 경우가 많아요. 한 명이 준비완료 체크한 걸 다른 명이 새로고침 없이 바로 볼 수 있어야 중복·누락이 안 생깁니다.
